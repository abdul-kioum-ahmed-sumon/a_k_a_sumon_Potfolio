## 🛠️ Technology Stack
- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8 + `@tailwindcss/vite`
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Animations**: GSAP 3 + ScrollTrigger (with `prefers-reduced-motion` compliance)
- **Icons**: Lucide Icons & Custom SVG components
- **Interactions**: Canvas Confetti & Clipboard API

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/abdul-kioum-ahmed-sumon/a_k_a_sumon_Potfolio.git
cd a_k_a_sumon_Potfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
